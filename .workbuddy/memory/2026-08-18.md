# 2026-08-18 工作日志

## NewAPI 限速网关微服务方案设计

- 设计了基于 NewAPI 的无侵入式限速网关架构：客户端 → 限速网关(微服务) → NewAPI → 上游 LLM
- 核心方案：Redis ZSET 滑动窗口 + Lua 原子脚本，实现 5h/7d/30d 三窗口限速
- 支持分组策略：API Key → 分组 → 限速配置，不同产品分组配额不同
- 两种限速模式：按请求数(ZSET) / 按 Token 用量(String 累加器)
- 两种限速粒度：按 Key 独立 / 按分组共享
- 技术栈：Python 3.11 + FastAPI + httpx(async proxy) + redis-py + SQLAlchemy + aiomysql
- 产出完整实施方案文档 + 可直接运行的项目代码（16 个文件）
- 项目路径：newapi-ratelimit-gateway/
- 文档路径：NewAPI-限速网关-完整实施方案.md

## Tool Call / Function Call 支持修复

- 分析了网关对 tool call 的兼容性：请求透传完全无感，问题集中在 token 模式的流式 usage 提取
- 修复 1（proxy.py）：流式 SSE 解析改用 buffer 累积 + `\n\n` 事件分割，解决 chunk 边界切割导致 usage 丢失的问题；先 yield 透传再解析，不阻塞客户端
- 修复 2（proxy.py + config）：token 模式 + 流式请求时自动注入 `stream_options.include_usage=true`（仅 /v1/chat/completions 路径，不覆盖客户端已设值），新增配置项 `ratelimit.auto_inject_include_usage` 可关闭
- 单元测试验证：SSE 边界切割场景 + 6 种注入场景全部通过
- 文档新增第 13 章「Tool Call / Function Call 支持说明」，含兼容性矩阵和实施步骤更新
